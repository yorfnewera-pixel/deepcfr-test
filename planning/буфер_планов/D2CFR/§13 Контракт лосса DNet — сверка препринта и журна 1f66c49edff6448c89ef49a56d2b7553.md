### 1.1 Журнал сам закрывает вопрос

Appendix B, стр. 18354, дословно:

> «...‖r̃^t(I) − V(I|θ^T)‖²₂ in the definition of loss function L_V mentioned in Section V-C2 or in DeepCFR [21] and ‖r̃^t(I) − r(I|θ^T)‖²₂ in D2CFR are consistent.»
> 

Авторы явно говорят: лосс D2CFR — это **тот же единственный MSE-лосс, что и в DeepCFR**, только с переименованным выходом (`V` → `r`). Если бы было второе слагаемое на `V`, это утверждение было бы ложным и всё доказательство развалилось бы. Значит «multiply loss function» в §III-B1 — это **описание агрегатора `⊕` на Fig. 4**, а не два члена лосса. Фраза неудачная, но скрытой формулы за ней нет.

## 2. Исправление № 1: про «нулевой градиент»

<aside>
❌

В предыдущей редакции я утверждал, что голова `V` получает точно нулевой градиент. **Это неверно.** Формулировка агента («можно прибавить одну и ту же константу») была точнее моей.

</aside>

Причина ошибки: я подставил параметризацию Dueling DQN (`V`-голова + `A`-голова, `Q = V + A`). У D2CFR она другая. Alg. 2, строка 8: `r_{i,NN}(I(h),a|θi) = V_i(I(h),a|θi) − V_i(I(h))`. Головы — это **`Q` и `V`**, а regret есть их разность. Поэтому:

```
∂L/∂Q(I,a) = 2·(r_NN − r̃)(a)
∂L/∂V(I)   = −2·Σ_a (r_NN − r̃)(a)
```

Обе головы получают ненулевой градиент, но **только через разность**: преобразование `Q(I,·) += c(I)`, `V(I) += c(I)` оставляет лосс бит в бит. Константа своя для каждого инфосета.

### 2.1 Настоящий аргумент за `L_v`

Сама по себе сдвиговая свобода безвредна для политики. Но в D2CFR она **фатальна для rectification**. Alg. 2, строка 9:

```
V_i(I(h)) = α·V_{i,NN}(I(h)|θi) + β·V_{i,MC}(I(h))
```

`V_MC` — среднее из 800 роллаутов в **абсолютной шкале выплат**. Складывать его с `V_NN`, определённым лишь с точностью до произвольной константы, — операция без смысла. Значит авторы **обязаны** были чем-то заякорить `V_NN` в абсолютной шкале, и этого они не описали. Наш `L_v` — закрытие именно этой дыры.

Побочное следствие: при `d2cfr_mc_correction_enabled: false` этот аргумент не действует, и `λ_v` остаётся чисто стабилизационным средством. Поэтому абляция по `λ_v` — обязательная, а не желательная.

## 3. Исправление № 2: где применяется rectification

<aside>
❌

В предыдущей редакции я написал: «rectification применяется только при построении целей, на inference никогда». **В статье ровно наоборот.**

</aside>

Algorithm 2 читается однозначно:

| Строки | Что происходит | Rectification |
| --- | --- | --- |
| 8–10 (traverser), 17–18 (оппонент) | `σ^t(I)` считается RM от `r_NN = V(I,a) − V(I)`, где `V(I) = α·V_NN + β·V_MC` | **Да** |
| 12–13 | `v(a)` — реальный возврат рекурсивного обхода; `r̃(I,a) = v(a) − Σ σ(I,a')·v(a')` | **Нет** |
| 15 | `(I, t, r̃^t(I)) → M_V` | **Нет** |

То есть цели обучения всегда чистые, посчитанные от фактических листьев дерева. Rectification влияет на обучение только **косвенно** — через то, что при лучшей оценке `V(I)` получается более вменяемая `σ^t`, а значит и более осмысленные `r̃`.

Правильная спецификация для реализации:

- rectification — часть **forward-пути вычисления стратегии во время обхода**, для обоих игроков
- цели `Q_target`, `V_target`, `r_target` ректификации **не содержат никогда**
- стоимость: `N = 800` роллаутов на **каждый** узел обхода обоих игроков. Для нашего HU без абстракции карт это огромный бюджет — ещё один аргумент держать `d2cfr_mc_correction_enabled: false` до зелёного ядра

## 4. Принятый контракт лосса

`dnet_loss: anchored` — дефолт.

### 4.1 Буфер

| Поле | Содержание |
| --- | --- |
| `I` | кодировка инфосета |
| `t'` | номер итерации |
| `legal_mask` | маска легальных действий |
| `Q_target[a]` | `v(a)` из Alg. 2 стр. 12 — возврат обхода |
| `V_target` | `Σ_a σ(I,a)·v(a)` — второе слагаемое из Alg. 2 стр. 13 |

Оба числа уже считаются в строке 13 самой статьи — мы не добавляем вычислений, только не выбрасываем промежуточные результаты. `r_target` не хранится, а считается как `Q_target[a] − V_target` → инвариант `r = Q − V` выполнен по построению.

### 4.2 Лосс

```
w = (t' / T)^p,   p = 1.0

L_r = w · Σ_{a ∈ legal} Huber( r_NN(I,a|θ) − (Q_target[a] − V_target) )
L_v = w · Huber( V_NN(I|θ) − V_target )

L_total = λ_r · L_r + λ_v · L_v      λ_r = 1.0,  λ_v = 0.5
```

- `L_r` точно соответствует Alg. 1 стр. 9 (Huber вместо MSE — наше отклонение ради устойчивости, в абляцию)
- `L_v` — наше добавление, обоснованное §1.2 («mean counterfactual value») и §2.1 (шкала для rectification)
- **`L_q` отсутствует**: при головах `Q` и `V` лосс на `Q` даёт ту же информацию, что `L_r + L_v`, и лишь перекашивает эффективные веса. Текущий трёхчленный лосс проекта сократить до двух; `d2cfr_joint_loss` остаётся `false`
- Вес `w` применяется к каждому слагаемому отдельно, не к сумме
- `Train θi from scratch` — сохраняется (Alg. 1 стр. 9), т.е. сеть переинициализируется каждую итерацию
- Отрицательные regrets в `L_r` без обрезки; `max(·,0)` — только в RM

### 4.3 Абляции

| Параметр | Значения | Смысл |
| --- | --- | --- |
| `λ_v` | `0.0`, `0.25`, `0.5`, `1.0` | `0.0` — точная буква статьи |
| `dueling_aggregator` | `literal`, `mean_subtract` | `mean_subtract` — не репликация |
| loss fn | `huber`, `mse` | `mse` — буква статьи |

Обязательный лог: `mean |V_NN|` и `std(V_NN − V_target)` по итерациям. При `λ_v = 0` ожидаем дрейф — это прямая эмпирическая проверка аргумента из §2.1.

## 5. Пункт 4 (`V_MC ≥ 0`) — уточнение после сверки

В препринте доказательство идёт иначе и **не требует неотрицательности**:

```
V(I,a|θ) ≤ α·V_NN(I,a|θ) + ω·β·V_NN(I,a|θ) = (α + ω·β)·V_NN(I,a|θ)
```

где `ω` — просто конечная константа пропорциональности, и далее `L_V − L_V* ≤ ω·ε_L`. Журнал этот ход выбросил и заменил на (28)–(30) с явным `V_MC(I) ≥ 0`.

<aside>
⚠️

Оба варианта нестрогие: препринт постулирует пропорциональность `V_MC` и `V_NN` без обоснования, журнал постулирует неотрицательность, ложную в zero-sum игре. Решение без изменений: **«без заявления о сохранении доказательства»**, `payoff scaling [−1, +1]` остаётся, в логах `MC rectification: heuristic (no theoretical claim)`.

</aside>

Полезный факт из Appendix B: при `t ≥ 99` выполняется `β = 0`, `α = 1`, и D2CFR **тождественно совпадает с DeepCFR по границе regret**. То есть вся проблемная теория касается только первых 98 итераций из 1000. При наших горизонтах это шум.
