# Отчёт 037 — фиксированная конфигурация B1, checkpoint 5000

Дата: 2026-08-28.

## Цель

После B1 и двух малых sweep (`particles`, `eta`) зафиксировать одну
конфигурацию и проверить её на большей paired выборке без дальнейшего тюнинга.

## Конфигурация

`light_checkpoint_iter_5000.pt`, B1 sequential resampling, 256 proposals,
128 rollout particles, `eta=10`, `min_ess=8`, `min_ess_ratio=0.03125`,
`resample_ess_ratio=0.5`, `min_root_gap_zscore=1`.

8 независимых seed (`107, 109, 113, 127, 131, 137, 139, 149`) × 16 deals.
Запуск занял примерно 10 минут wall time и не изменял training/checkpoint.

## Результат

| Метрика | Значение |
|---|---:|
| Paired samples | 768 |
| Search roots | 263 |
| B1 resampling | 924 |
| ESS fallback | 0 |
| Noise-gate fallback | 130 |
| Roots, дошедшие до MMDS | 133 |
| Суммарные смены argmax | 27 |
| Pooled EV | -21.35 bb/100 |
| CI95 pooled EV | [-177.55, 134.84] bb/100 |
| t-statistic | -0.268 |

## Интерпретация

1. B1 устойчиво снял исходный структурный блокер: в 263 roots не было ни
   одного fallback по ESS.
2. Примерно половина roots проходит noise-gate и действительно меняет policy;
   это не «пустой» runtime path.
3. EV-интервал всё ещё широк и содержит ноль. Точечное значение -21.35
   bb/100 не является доказательством ухудшения, как и прежние положительные
   point estimate не были доказательством улучшения.
4. Новые sweep `eta` и particles сейчас не оправданы: единственный честный
   следующий EV-шаг — значительно более крупная заранее зафиксированная
   оценка. Она будет дорогой при нынешних ~10 мин на 768 samples и не должна
   выполняться параллельно с важным обучением без отдельного решения.

Артефакт данных: `036-b1-fixed-config-checkpoint-5000.json`.
