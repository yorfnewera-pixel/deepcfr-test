# Bug #67: Унификация шкал sizing_q и стратифицированный sampling

## Статус: FIXED

## Описание

После фикса #66 (стабилизация q_net) raise_freq вырос с 0.9% до 5.2%, но sizing всё ещё
коллапсировал в 0.10 (best_sizing_anchor_dist = 0.10 в 2993/2993 состояний).

Диагностика выявила два дефекта в sizing_q:

### Дефект 1: рассинхрон шкал между source

`SizingQBuffer` хранит targets от трёх источников:

| Source | Что | Единицы |
|--------|-----|---------|
| 0 | on-policy (реальный исход) | raw chips |
| 1 | probe (exploration) | raw chips |
| 2 | lookahead (bootstrap) | **bb** (через q_net после фикса #66) |

`_bootstrap_sizing_value` возвращает `sum(strategy * q_net(...))`, а q_net после фикса #66
учится на `reward / _get_q_reward_unit()` (= `reward / big_blind`). Терминальная ветка
lookahead и source 0/1 — в raw chips. В один MSE-буфер падают разные единицы.

На iter_200: source 2 targets ≈ -0.01 (плоско), source 0 targets ≈ -0.37…-2.5.
Рассинхрон ~30-100×. Сеть учит доминирующую поверхность source 0.

### Дефект 2: несбалансированный sampling

`SizingQBuffer.sample()` — равномерный `np.random.choice` по всему буферу.
`_anchor_counts` используется только как coverage-gate, не в сэмплинге.
Source 0 (67%) и анкоры 0.10/0.25 доминируют в MSE → самоподдерживающаяся петля.

## Изменения

### 1. Унификация шкалы: `sizing_q_bootstrap_scale_fix`

**Файл:** `src/core/deep_cfr.py` — метод `_bootstrap_sizing_value`

При флаге `sizing_q_bootstrap_scale_fix=True` возвращаемое значение домножается
на `self._get_q_reward_unit()` (= `big_blind`):

```python
v = float((strategy * q_vals).sum().item())
if self.sizing_q_bootstrap_scale_fix:
    v *= self._get_q_reward_unit()
return v
```

Теперь bootstrap-значение в raw chips — совпадает с терминальной веткой lookahead
и source 0/1. /pot нормализация в `_normalize_sizing_q_target` применяется ко всем
единообразно.

### 2. Стратифицированный sampling: `sizing_q_stratified_sampling`

**Файл:** `src/core/deep_cfr.py` — класс `SizingQBuffer`

Новый метод `sample_stratified(batch_size, num_anchors)`:

```python
def sample_stratified(self, batch_size, num_anchors):
    ...
    per_anchor = batch_size // n_present
    for anchor in present:
        pool = all_indices[anchors == anchor]
        take = min(per_anchor, len(pool))
        chosen.extend(...)
    ...
```

- Равная квота на каждый непустой анкер.
- Малые группы — с заменой (replace=True).
- Остаток добирается случайно.
- fallback: если `n_present <= 1` или буфер пуст — старый uniform.

**Файл:** `src/core/deep_cfr.py` — метод `train_sizing_q_network`

```python
if self.sizing_q_stratified_sampling:
    samples = self.sizing_q_buffer.sample_stratified(
        batch_size, num_anchors=self.num_anchors)
else:
    samples = self.sizing_q_buffer.sample(batch_size)
```

### 3. Config

**Файл:** `config.yaml`

```yaml
sizing_q_bootstrap_scale_fix: true      # Шаг 1: bb→raw chips в bootstrap
sizing_q_stratified_sampling: true      # Шаг 2: стратификация по анкорам
```

### 4. Чекпоинты

Флаги сохраняются в `config_dict` чекпоинта и восстанавливаются из `_load_checkpoint`.

### 5. Тесты

**Файл:** `tests/test_hybrid_outcome_sampling.py`

Добавлены 4 теста:
- `test_sizing_q_bootstrap_scale_fix_on` — проверка домножения на reward_unit
- `test_sizing_q_bootstrap_scale_fix_off` — без флага не домножается
- `test_sizing_q_buffer_stratified_limits_anchor_bias` — стратификация не даёт доминировать
- `test_train_sizing_q_network_uses_stratified_when_enabled` — флаг включает стратификацию
- `test_checkpoint_saves_sizing_q_flags` — сохранение в чекпоинт

Результат: 31/31 passed.

## Что не трогалось

- `_normalize_sizing_q_target` — без изменений
- `_hierarchical_sizing`, `choose_action`, inference — не клампят к 0.10, argmax следует за Q
- Flatness bootstrap-V — отложено до метрик после прогона
- `eps decay`, `sizing_min_prob` — будут отдельным фиксом после восстановления разнообразия
