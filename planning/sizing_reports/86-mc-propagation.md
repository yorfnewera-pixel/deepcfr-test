## 0. Pre-registered критерии (зафиксированы ДО запуска)

### Мотивировка

#84b relapse analysis нашёл smoking gun: у ВСЕХ raise-сэмплов в q_buffer `reward=0.0`, `is_terminal=False`. Advantage-сеть физически не может удержать raise > fold без сигнала об исходе руки.

**Решение:** в момент `q_buffer.add` писать `v_sampled` (сэмплированный return остатка руки) вместо `0.0`, и ставить `is_terminal=True` (отключает bootstrap-член в target). Две точки вставки в `deep_cfr.py`: hero_os (~строка 2238) и opponent (~строка 2518).

## 2. Вывод: PARTIAL (M1 PASS, M2 PASS со small flip, B FAIL с plateau)

**M1:** PASS — smoking gun устранён, raise получает terminal reward.

**M2:** PASS условно — adv_fold mini-flip (+0.60, в 14× меньше #84: +8.47), |δ adv_raise|=0.27 < 1.0, буфер fold НЕ взорвался (fold count уменьшился с 17.8% до 12.3%). **Relapse-распад отсутствует — это главный научный результат #86.** Вместо relapse — плато: raise_freq застрял на ~21% и не восстанавливается.

**B:** FAIL — raise < 40%, top-2 > 55%, анкер 0.10 доминирует. Политика в call-station equilibrium.

**Причина плато:** сырые чипсовые цели (target_term 36-39, std 152) слишком шумные — fit_ratio застревает на 0.14. Q-сеть предсказывает ~5 при целях ~37 — не хватает точности чтобы вытянуть политику из коллапса. Нужна нормализация целей → #87 pot-relative.
