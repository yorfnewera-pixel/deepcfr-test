Использую `writing-plans` для итогового плана внедрения осторожного Q-assisted sizing. План ниже рассчитан на работу агентом в несколько этапов; текущий код не изменялся.

# Q-Assisted Sizing With CFR Priority

> **Для агента:** использовать `subagent-driven-development` или `executing-plans`. Каждый этап выполнять отдельно, сначала тесты, затем код. Не подключать Q к основной sizing policy до прохождения offline shadow-проверок.

**Цель:** добавить Q как вспомогательную аппроксимацию несыгранных доступных sizing-анкеров, сохранив grounded CFR-значения сыгранных анкеров и рабочий чистый CFR-режим как обязательный baseline.

**Архитектура:**

```text
advantage_sizing_net:
    текущая CFR sizing policy и regret matching

sizing_q_net:
    Q(state, anchor_size) для оценки несыгранных анкеров

grounded values:
    приоритетный сигнал для реально кредитуемых анкеров

q_hybrid:
    grounded values для credited anchors
    Q estimates для legal uncredited anchors
    illegal anchors исключаются
    затем EV → regrets → regret matching
```

`q_hybrid` должен быть feature flag. При выключенном флаге результат и sampling текущего `sizing_cfr_mode` должны оставаться без изменений.

**Tech Stack:** Python 3.11, PyTorch, NumPy, `pokers`, pytest, существующие `SizingAdvantageBuffer`, `SizingQBuffer`, sizing diagnostics.

## Task 5: Добавить offline shadow hybrid

- Modify: `tools/diagnose_sizing_input_discrimination.py`
- Create: `tools/diagnose_sizing_hybrid.py`
- Test: `tests/test_sizing_q_regret.py`

Shadow режим не должен менять checkpoint, training buffers или production policy.

Для одного sizing state построить три distributions:

```text
cfr:
    full_probs от advantage_sizing_net

q:
    Q по всем legal anchors
    baseline/advantage conversion
    regret matching

hybrid:
    grounded для credited
    Q для uncredited legal
    regret matching
```

Для hybrid:

```python
values = q_values.copy()

values[credited_indices] = grounded_values[credited_indices]
values[illegal_indices] = 0.0

ev = weighted_baseline(values, ...)
regrets = values - ev
regrets[illegal_indices] = 0.0
policy = regret_matching_anchors(regrets, min_prob=...)
```

Важное ограничение:

```text
Q не заменяет grounded credited values.
Q используется только для legal uncredited anchors.
```

Сравнивать:

```text
TV(cfr, grounded policy)
TV(q, grounded policy)
TV(hybrid, grounded policy)
TV(..., uniform)
```

Также:

```text
entropy
top anchor
legal anchor count
credited count
uncredited count
max Q-min Q
value spread
```

До подключения в traversal нужно проверить shadow на фиксированном holdout.

## Task 8: Не позволить Q менять dominant CFR anchor без основания

Твоя поправка про 20% правильна: exploration не должен отнимать у dominant anchor его обычную CFR-массу.

Текущий механизм оставить:

```text
80%:
    выбрать наиболее вероятный доступный anchor в bucket через argmax

20%:
    выбрать случайный доступный anchor внутри этого bucket
```

Это bucket-level exploration, а не 20% игры для каждого из 15 anchors и не
равномерный floor по anchors. Для bucket-ов `small=[0.10, 0.25]`,
`medium=[0.33, 0.50, 0.66, 0.75]`,
`large=[1.00, ..., 3.00]` условная вероятность недоминирующего anchor в
exploration-событии равна соответственно 10%, 5% и примерно 2.22%.
Dominant anchor сохраняет свою CFR-массу и дополнительно может быть выбран
во время exploration.

Не заменять эту sampling policy Q-guided choice на первом этапе.

В hybrid режиме Q влияет только на value/regret vector для uncredited anchors. Однако для защиты baseline добавить diagnostics:

```text
cfr_top_anchor
hybrid_top_anchor
cfr_mass_on_top
hybrid_mass_on_top
mass_delta_total_variation
```

Порог на первом shadow/run не применять автоматически. Сначала только логировать.

Если hybrid резко переносит массу с dominant CFR anchor, это должно быть видно в логе, но не должно маскироваться под обычный sizing exploration.

## Критерии успеха

### Техническая корректность

```text
1. cfr mode полностью совпадает с текущим baseline.
2. hybrid fallback работает, когда Q not ready.
3. illegal anchors всегда имеют zero policy mass.
4. grounded credited values никогда не заменяются Q.
5. uncredited legal anchors получают Q только в hybrid.
6. Q не меняет собственные training targets.
7. Q buffer coverage логируется по 15 anchors.
8. action Q остаётся выключенной.
9. full epochs действительно покрывают buffer.
10. checkpoint lifecycle сохраняет режим и diagnostics.
```

### Качество

Не требовать немедленного выигрыша против random. Сначала:

```text
Q ranking > random
hybrid policy не хуже CFR на grounded holdout
```

Затем:

```text
q_hybrid лучше cfr на независимом sizing gate
```

и только потом:

```text
q_hybrid лучше uniform по игровой метрике
```

## Итоговая последовательность

```text
CFR policy
    ↓
real sampled sizing anchors
    ↓
grounded values для credited anchors

Q training
    ↓
Q(state, size) для legal uncredited anchors
    ↓
offline ranking/coverage audit

если Q прошла audit:
    grounded + Q hybrid
    ↓
sizing regrets
    ↓
regret matching
    ↓
K-collapse sampling

если Q не прошла audit:
    остаёмся на чистом CFR baseline
```

Да, я согласен с твоим уточнением: текущая bucket exploration не должна рассматриваться как гарантия равномерного исследования 15 анкоров. Но её роль может быть именно такой, как ты описал: в основном сохранять доминирующий CFR anchor и лишь иногда пробовать альтернативы внутри каждого доступного bucket-а. Q нужна не для того, чтобы отнять массу у доминирующего анкера заранее, а чтобы дать оценку legal uncredited anchors в отдельном hybrid-режиме.
