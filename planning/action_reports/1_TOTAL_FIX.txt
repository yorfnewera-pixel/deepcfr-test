ПРОБЛЕМА
========
IEEE 754 f64: call_amount + additional = stake + 1e-14
Rust: if bet > stake { return HighBet } — строгое сравнение без epsilon
Результат: HighBet на точных all-in границах, ломает CFR тренировку

Два конкретных сценария HighBet:
1. Float-перебор: stake=200.0, call=20.0, additional=180.0
   bet = 20.0 + 180.0 = 200.00000000000003 > 200.0 → HighBet
2. Python не обрезал additional: сеть выдаёт amount > remaining_after_call

Бонус-баг: зависание игры когда все активные игроки all-in (stake=0)
all_same_bet требует is_last_player, но all-in игроки бесконечно Check

6B. src/agents/random_agent.py — весь файл
─────────────────────────────────────────────────────────────────────

import random
import pokers as pkrs


class RandomAgent:
    def __init__(self, player_id):
        self.player_id = player_id
        self.name = f"RandomAgent_{player_id}"

    def choose_action(self, state):
        if not state.legal_actions:
            return pkrs.Action(pkrs.ActionEnum.Fold)

        action_enum = random.choice(state.legal_actions)

        if action_enum != pkrs.ActionEnum.Raise:
            return pkrs.Action(action_enum)

        player_state = state.players_state[state.current_player]
        call_amount = max(0, state.min_bet - player_state.bet_chips)
        remaining = player_state.stake - call_amount
        min_raise = max(1.0, float(state.bb)) if hasattr(state, 'bb') and state.bb and float(state.bb) > 0 else 1.0

        if remaining < min_raise:
            if pkrs.ActionEnum.Call in state.legal_actions:
                return pkrs.Action(pkrs.ActionEnum.Call)
            return pkrs.Action(pkrs.ActionEnum.Fold)

        options = [min_raise]
        half_pot = max(state.pot * 0.5, min_raise)
        if half_pot <= remaining:
            options.append(half_pot)
        full_pot = max(state.pot, min_raise)
        if full_pot <= remaining:
            options.append(full_pot)
        if remaining >= min_raise and remaining not in options:
            options.append(remaining)

        options = [a for a in options if min_raise <= a <= remaining]
        if not options:
            if pkrs.ActionEnum.Call in state.legal_actions:
                return pkrs.Action(pkrs.ActionEnum.Call)
            return pkrs.Action(pkrs.ActionEnum.Fold)

        additional = round(random.choice(options), 2)
        return pkrs.Action(pkrs.ActionEnum.Raise, additional)

АРХИТЕКТУРНАЯ СХЕМА: КТО ЗА ЧТО ОТВЕЧАЕТ
═══════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────┐
│                      PYTHON                                 │
│                                                             │
│  round(additional, 2)  ← чистит float-шум от сети/pot      │
│  max(additional, min_raise)  ← клип снизу (легальный рейз)  │
│  min(additional, remaining)  ← клип сверху (не-оллин)      │
│                                                             │
│  НЕ делает: epsilon, -0.01, fallback на Call                │
└──────────────────────┬──────────────────────────────────────┘
                       │ Action(Raise, additional)
                       ▼
┌─────────────────────────────────────────────────────────────┐
│                       RUST                                   │
│                                                             │
│  current_player_can_raise()  ← Raise в legal_actions?       │
│    (из коммита b1a48bd: remaining_after_call > CHIP_EPSILON) │
│                                                             │
│  bet = call_amount + additional                             │
│  if bet > stake: bet = stake  ← CLAMP (auto all-in)        │
│  if all_broke: round_ended   ← фикc зависания              │
│                                                             │
│  НЕ делает: epsilon-сравнение, HighBet                      │
└─────────────────────────────────────────────────────────────┘

Границы:

  НИЖНЯЯ (additional < min_raise):
    Python: max(additional, min_raise)
    Rust: current_player_can_raise() → Raise не в legal_actions

  ВЕРХНЯЯ (bet > stake):
    Python: min(additional, remaining_after_call)
    Rust: clamp bet = stake (auto all-in)

  СЕРЕДИНА (min_raise ≤ additional ≤ remaining):
    Python: round(additional, 2) — только косметика, валидность не нарушается
    Rust: ничего, bet ≤ stake всегда

═══════════════════════════════════════════════════════════════════
ПОЧЕМУ round(x,2) А НЕ math.floor(x*100)/100
═══════════════════════════════════════════════════════════════════

math.floor(0.29 * 100) / 100 = 0.28  ← БАГ!

0.29 в f64 = 0.28999999999999998002
0.29 * 100 = 28.999999999999996...
floor(28.999...) = 28
28 / 100 = 0.28  ← ПОТЕРЯ $0.01

573 из 10000 двухдесятичных значений ломаются на floor.
round() использует "round half to even" (banker's rounding) — корректен.

═══════════════════════════════════════════════════════════════════
ПОЧЕМУ CLAMP А НЕ EPSILON (bet > stake + CHIP_EPSILON)
═══════════════════════════════════════════════════════════════════

bet = 200.00000000000003, stake = 200.0

epsilon-подход: bet < stake + 1e-9 → OK, пропускаем
  Но: stake -= bet → stake = -3e-14  ← ОТРИЦАТЕЛЬНЫЙ СТЕК!
  min_bet = bet_chips = 200.00000000000003 ← ГРЯЗНЫЙ min_bet
  Следующий round: ещё грязнее → НАКОПЛЕНИЕ ШУМА

clamp-подход: bet > stake → bet = stake = 200.0
  stake -= 200.0 → stake = 0.0  ← ЧИСТЫЙ НОЛЬ
  min_bet = bet_chips = 200.0  ← ЧИСТЫЙ
  min_raise для следующего round тоже чистый → НЕТ НАКОПЛЕНИЯ

═══════════════════════════════════════════════════════════════════
ПОЧЕМУ НЕ FALLBACK НА CALL КОГДА additional < min_raise ПОСЛЕ round
═══════════════════════════════════════════════════════════════════

Если CFR выбрал action_type=2 (Raise), но Python возвращает Call:
  - Regret для Raise считается вдоль траектории Call
  - counterfactual_value[Raise] = value(Call) ← НЕВЕРНО!
  - CFR "думает" что Raise дал тот же результат что Call
  - Это искажает стратегию: Raise недооценивается

Правильно: если Raise выбран — вернуть Raise.
  Rust current_player_can_raise() уже гарантирует что Raise легален
  Python clip (max с min_raise) гарантирует minimum raise size
  round(x,2) никогда не обрежет ниже min_raise (сдвиг max ±0.005)
