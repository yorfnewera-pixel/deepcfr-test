БАГ-РЕПОРТ #35: Q-Network Variance Reduction (VR-DeepDCFR+)
================================================================================

ТИП: Новая фича
ДАТА: 2026-05-14
СТАТУС: Реализовано, протестировано

================================================================================
ОПИСАНИЕ
================================================================================

Реализован Q-Network Variance Reduction (VR-DeepDCFR+) для снижения
дисперсии на opponent nodes в CFR traversal.

Проблема: на opponent node сэмплируется одно действие â ~ σ_opp, затем
рекурсивно считается v_sampled = cfr_traverse(new_state). Информация от
остальных действий оппонента теряется → высокая variance.

Решение: control variate через Q-baseline:
  baseline     = Σ σ_opp(a) · Q(s, a)    — ожидаемое значение по модели
  correction   = v_sampled - Q(s, â)      — поправка для сэмплированного
  adjusted     = baseline + correction

Несмещённость: E[adjusted] = Σ σ(a)·v(a) = v(I) при ЛЮБОМ Q.
Хорошее Q → correction ≈ 0 → variance резко падает.

================================================================================
БАГФИКС: next_encoded perspective
================================================================================

В исходном плане был баг:
  next_encoded = encode_state(new_state, current_player)  # СТАРЫЙ

После apply_action current_player сменился. Q-net при inference использует
encode_state(state, state.current_player) — perspective ТЕКУЩЕГО decision maker.
TD-target V(s') тоже должен использовать perspective нового decision maker.

Исправлено:
  next_encoded = encode_state(new_state, new_state.current_player)  # НОВЫЙ

================================================================================
МИНИОР: SPR → Pot Commitment Ratio
================================================================================

БАГ: SPR = min(Stack/Pot, 15.0) — жёсткий clip на 15.0 теряет информацию
при высоком SPR (15, 50, 200 — одинаковы для сети), плюс разрыв градиента
на границе clip.

ФИКС: Pot Commitment Ratio = Pot / (Pot + Stack) = 1 / (1 + SPR)
  - Диапазон (0, 1] — уже нормализовано, нет clipping
  - SPR=0 → 1.0 (коммитед), SPR→∞ → 0.0 (глубокий стек)
  - Плавная функция, градиент всюду определён
  - Больше разрешения в критическом диапазоне SPR 0–4

Файл: src/core/model.py, encode_state()
  СТАРЫЙ: spr_feat = [min(player_stake_enc / player_pot_enc, 15.0) ...]
  НОВЫЙ:  pot_commitment = player_pot_enc / (player_pot_enc + player_stake_enc) ...

Файл: inference/core.py, encode_state()
  СТАРЫЙ: spr_feat = [min(player_stake_enc / player_pot_enc, 15.0) ...]
  НОВЫЙ:  pot_commitment = player_pot_enc / (player_pot_enc + player_stake_enc) ...
  + описание фичи: "spr_feat" → "pot_commitment"
