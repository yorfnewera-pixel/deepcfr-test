# Bug #34: Микрооптимизации cfr_traverse_multi

## Статус: FIXED

## Описание

Три микрооптимизации в `cfr_traverse_multi` для ускорения traversal:
1. Дубль `get_legal_action_mask` в opponent branch — маска пересчитывалась, хотя `legal_mask` уже известна
2. `mean_sizing` считался всегда, даже когда Raise не выбран — лишний forward sizing_head
3. `torch.FloatTensor` создавал лишнюю копию вместо `torch.from_numpy`

## Изменения

### 1. Убран дубль маски (opponent branch)

**Было:**
```python
opp_mask = self.get_legal_action_mask(state)
opp_legal = [a for a in range(self.num_actions) if opp_mask[a] > 0]
```

**Стало:**
```python
opp_mask = legal_mask
opp_legal = legal_action_types
```

`get_legal_action_mask(state)` зависит только от `state.legal_actions`, которые относятся к `state.current_player`.
В одном узле дерева маска одна и та же — повторный вызов лишний.

### 2. Ленивый mean_sizing

**Было:**
```python
opp_bet_size = self.advantage_net.mean_sizing(opp_z_mean[0:1]).item()
...
if action_type == 3:
    pokers_action = self.action_type_to_pokers_action(action_type, state, opp_bet_size)
```

**Стало:**
```python
if action_type == 3:
    opp_bet_size = self.advantage_net.mean_sizing(opp_z_mean[0:1]).item()
    pokers_action = self.action_type_to_pokers_action(action_type, state, opp_bet_size)
```

`mean_sizing` вызывается только когда выбран Raise (action_type == 3).

### 3. torch.from_numpy вместо torch.FloatTensor

**Было:**
```python
state_tensor = torch.FloatTensor(encoded_state).to(self.device)
```

**Стало:**
```python
state_tensor = torch.from_numpy(encoded_state.astype(np.float32, copy=False)).to(self.device)
```

`torch.from_numpy` создаёт тензор без копии данных (shared memory).
Применено во всех местах: traversing branch, opponent branch, choose_action.
