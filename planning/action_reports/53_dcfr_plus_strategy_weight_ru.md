ОПИСАНИЕ
────────

Формула веса усреднения стратегии в DCFR+ согласно статье:
  loss = (t / T)^γ · Σ(σ - Π)²

Где вес (t/T)^γ умножает loss ОДИН РАЗ.

Старый код использовал F.mse_loss(pred * w, target * w), что
КВАДРАТИЛО вес: w²·(pred - target)². Это давало правильный
эффективный вес (t/T)² только случайно — через компенсацию
формулы (t/T*2)^(γ/2).

Исправление: per-sample MSE с явным умножением веса один раз.


═══════════════════════════════════════════════════════════════════
  ПУНКТ 1 — КРИТИЧЕСКИЙ (ИСПРАВЛЕНО)
  train_strategy_network: per-sample MSE, вес один раз
═══════════════════════════════════════════════════════════════════

  Файл: src/core/deep_cfr.py:1925-1940

  Было (скрытое квадратирование веса):
    weights = torch.pow(iteration_tensors / T * 2, self.discount_gamma / 2)
    ...
    weights_expanded = weights.unsqueeze(1)
    action_loss = F.mse_loss(
        predicted_policies * weights_expanded,
        policy_tensors * weights_expanded.detach())

  Эффект: MSE(σ·w, Π·w) = w²·(σ-Π)² — вес квадратился.
  Формула (t/T*2)^(γ/2) при γ=2 давала 2t/T, квадрат = 4(t/T)².
  Случайно совпадало со статьёй, но неочевидно при чтении.

  Стало (вес один раз, явно):
    weights = torch.pow(
        torch.clamp(iteration_tensors / T, min=1e-6),
        self.discount_gamma)

    per_sample_loss = (
        (predicted_policies - policy_tensors) ** 2 * mask_tensors
    ).sum(dim=1)
    action_loss = (per_sample_loss * weights).mean()

  Эффект при γ=2: вес = (t/T)², применяется один раз.
  Формула явно соответствует статье: loss = (t/T)^γ · Σ(σ-Π)².


═══════════════════════════════════════════════════════════════════
  ПУНКТ 2 — СРЕДНИЙ (ИСПРАВЛЕНО)
  train_strategy_sizing_anchor_network: KL-div, вес один раз
═══════════════════════════════════════════════════════════════════

  Файл: src/core/deep_cfr.py:1968, 1973-1974

  Текущая формула:
    iter_weights = torch.pow(
        torch.clamp(iter_tensors / t, min=1e-6),
        self.discount_gamma)
    ...
    kl_per_sample = F.kl_div(pred_log_probs, target_weights_t,
                              reduction='none').sum(dim=1)
    loss = (kl_per_sample * iter_weights).mean()

  Здесь вес изначально применялся один раз (per-sample KL),
  проблема была только в формуле: (t/T*2)^(γ/2) давало 2t/T
  при γ=2 — линейный вес вместо квадратичного.
  Исправлено: (t/T)^γ — правильный вес.
