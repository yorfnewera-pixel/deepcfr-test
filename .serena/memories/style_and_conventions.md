# Стиль кода и конвенции

## Комментарии
- Только на русском языке
- Только для сложных алгоритмов, бизнес-правил, workarounds
- Объяснять намерение/причину, а не повторять код

## Дизайн-принципы
- SOLID, DRY, KISS, YAGNI
- Самодокументируемый код с понятными именами
- Удаление неиспользуемого кода
- Big O в критических путях (CFR/poker AI)

## Обработка ошибок
- Робустная обработка исключений
- Логирование для диагностики (без утечки чувствительных данных)
- STRICT_CHECKING флаг в src/utils/settings.py

## Управление изменениями
- При конфликте новых инструкций с текущей логикой — остановиться и спросить
- Сохранять существующую функциональность при модификациях
- Верифицировать с пользователем перед удалением/существенным изменением рабочего кода

## Типизация
- Type hints не используются системно (Python 3.11, без --strict)
- Имена функций/классов: snake_case для функций, PascalCase для классов
- Префикс _ для приватных методов

## Context7
- Использовать Context7 MCP для документации библиотек и генерации кода
