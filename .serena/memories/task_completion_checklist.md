# Чеклист при завершении задачи

1. **Запустить тесты**:
   ```
   python -m pytest tests/test_pokers_regressions.py tests/test_training_regressions.py -q
   ```

2. **Проверить импорты** — убедиться, что новые модули корректно импортируются

3. **Проверить lint/форматирование** — явных конфигов lint нет, но следить за:
   - PEP 8 базово
   - Отсутствие неиспользуемых импортов
   - Русские комментарии только где нужно

4. **Не коммитить** без явного запроса пользователя

5. **При изменении pokers/** — пересобрать: `cd pokers; maturin develop --release`

6. **При конфликте логики** — остановиться и спросить пользователя
